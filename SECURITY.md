# 🛡️ Security Policy

## Supported Versions

We actively maintain and provide security patches for the latest production release of MephistoMail.

| Version | Supported          |
| ------- | ------------------ |
| 2.4.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take the security and privacy of our users very seriously. If you discover a security vulnerability or privacy flaw in MephistoMail:

1. **Do not create a public GitHub issue.**
2. Please report your findings directly to our security maintainer via email:
   - **Email:** [jokallame0@gmail.com](mailto:jokallame0@gmail.com)
3. Include details of the vulnerability, steps to reproduce, and potential impact.
4. We will acknowledge receipt of your report within 24-48 hours and work with you on a responsible disclosure timeline.

Thank you for helping keep MephistoMail safe for everyone!
