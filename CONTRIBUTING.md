# 🤝 Contributing to MephistoMail

Thank you for your interest in contributing to MephistoMail! We welcome contributions from developers, designers, and translators worldwide.

## How to Contribute

### 1. Reporting Bugs
- Search existing GitHub Issues before opening a new one.
- Provide clear reproduction steps, browser version, and OS.

### 2. Suggesting Features
- Open a feature request issue describing the proposed functionality and motivation.

### 3. Submitting Code (Pull Requests)
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/my-new-feature`
3. Commit your changes: `git commit -m 'feat: Add awesome new feature'`
4. Ensure tests and build pass: `npm run build`
5. Push to the branch: `git push origin feature/my-new-feature`
6. Open a Pull Request on GitHub.

### 4. Adding Translations (i18n)
- MephistoMail supports 30 languages. If you find a translation error or want to improve localized strings, edit the files in `src/locales/` or `src/translations.ts`.
